# Translation glossary

Terms used in the interface (`po/*.po`) and in the manual (`docs/manual`).
Keep them consistent.

| English | Español | Deutsch |
|---|---|---|
| Lift angle | Ángulo de alzamiento | Hebungswinkel |
| Beat error | Error de batido | Abfallfehler |
| Rate (s/d) | Marcha (s/día) | Gangabweichung (s/t); narrow places: Gangabw. |
| Amplitude | Amplitud | Amplitude |
| Paperstrip | Diagrama de marcha | Gangdiagramm |
| Positional error | Error posicional | Lagenfehler |
| Position | Posición | Lage |
| Snapshot | Captura | Aufnahme |
| Trend | Tendencia | Verlauf |
| Run (Record to Pause) | Tramo | Abschnitt |
| Record / Pause | Grabar / Pausar | Aufzeichnen / Pause |
| Calibration | Calibración | Kalibrierung |

## Kept in English in every language

- Results table headers: RATE, AMP., B.E., L.A., BEAT, and the units shown
  there (s/d, ms, °).
- Position codes: DU, DD, CU, CD, CL, CR.
- Calibration status: cal (wait), cal (acq.), cal (done), cal (fail).
- Units outside the Trend page: ms, °, bph, dBFS, kHz.

## Numbers

Numbers always use a point as the decimal separator, in every language, on
screen and in the files.

## Style

- Spanish: *usted* in full sentences, infinitive in menus and buttons.
- German: infinitive in menus and buttons, *Sie* in full sentences.
